# BTM 495 – System Prototype

## Project Overview

This project is a Python prototype developed for BTM 495.

It demonstrates the implementation of our UML class diagram, including 26 classes, their attributes, basic inheritance relationships, and an SQLite database.

## Requirements

- Python 3.9 or newer
- No additional Python packages required

## How to Run the Prototype

**Step 1:** Download the repository using GitHub's **Code → Download ZIP** option.

**Step 2:** Extract the ZIP file.

**Step 3:** Open a terminal in the extracted project folder.

**Step 4:** Run the following command:

```bash
python main.py
```

On some systems, the command may be `python3 main.py`.

## Expected Results

The program will:

1. Create an SQLite database named `btm495.db`.
2. Initialize 26 database tables.
3. Demonstrate basic Python class functionality.
4. Display the results in the terminal.
